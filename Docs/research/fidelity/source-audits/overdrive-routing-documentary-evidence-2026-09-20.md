# SH-201 overdrive routing: documentary evidence

2026-09-20. **The published architecture supports post-filter overdrive, but does not draw an explicit OVERDRIVE signal-path node.** This conclusion is stronger than an inference from panel placement alone: the official specification assigns overdrive to AMP, and separate diagrams place AMP after FILTER. Exact internal ordering relative to amplitude-envelope multiplication remains unspecified.

| Official source | What is explicitly present | Limit |
| --- | --- | --- |
| [Owner's Manual p. 74](https://static.roland.com/assets/media/pdf/SH-201_OM.pdf#page=74), specifications | Under **“AMP section”**, the indented entry is **“Insertion Effect: Overdrive”**, alongside Level and the envelope. | Classifies overdrive as part of AMP; it does not diagram AMP's internal operations. |
| [Owner's Manual p. 75](https://static.roland.com/assets/media/pdf/SH-201_OM.pdf#page=75), block diagram | Grey audio arrows run MIX/MOD → FILTER → AMP for both Upper and Lower tones. Black AMP ENV control arrows enter AMP. The EFFECTS box explicitly contains DELAY and REVERB. | **No separate overdrive block appears.** The diagram alone does not locate distortion within AMP or expose additional internal processing. |
| [Owner's Manual p. 27](https://static.roland.com/assets/media/pdf/SH-201_OM.pdf#page=27), basic synthesis diagram | The same FILTER → AMP ordering, followed by an abstract EFFECTS block. | Overdrive is not individually shown. |
| [Owner's Manual pp. 38–39](https://static.roland.com/assets/media/pdf/SH-201_OM.pdf#page=39) | Overdrive is controlled from the AMP panel. Page 39 explains added harmonics and shows a generic boost/clipping waveform illustration. | The illustration contains no filter or envelope stage; knob/button location and distortion behavior alone do not prove routing. |
| [Owner's Manual p. 61](https://static.roland.com/assets/media/pdf/SH-201_OM.pdf#page=61), parameter table | The overdrive switch and drive amount belong to the AMP parameter group. | Parameter grouping does not specify internal execution order. |
| [Roland Synthesis 101, printed p. 13 / PDF p. 8](https://cdn.roland.com/assets/media/pdf/sh_201_synthesis_101.pdf#page=8) | The AMP chapter explicitly describes amplification of the oscillator signal after FILTER processing. Its panel illustration includes the overdrive button. | It supplies no separately identified overdrive route. |

The best supported reading is therefore **overdrive within the downstream AMP stage**. This combines an explicit specification classification with an explicit block ordering; it remains an architectural inference about the unlabelled distortion operation. No inspected source explicitly states that overdrive precedes the voice filter, and none specifies whether distortion is before or after the amplitude-envelope gain, its exact transfer curve, or any unshown internal filtering. The generic distortion explanation does not settle those questions.

Septum's current post-filter nonlinear implementation, and the [terminal-model audit](rcs-a02-terminal-model-2026-09-20.md) describing that implementation, establish only the local model's ordering. They must not be cited as proof of Roland's internal DSP. This audit makes no conclusion from A02/A03 audio residuals and changes no DSP.
