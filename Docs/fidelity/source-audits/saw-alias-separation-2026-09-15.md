# Simultaneous Saw alias separation

## Result

**Separating main harmonics and nearby alias branches simultaneously does not
remove the earlier oscillator-model failures.** The frozen asymmetric W4 model
still misses the note 93 / 10,660 Hz line by 16.62 dB and the note 88 / 7,182 Hz
line by 13.37 dB with both tested fold families included. No DSP or benchmark
default is changed.

This is a sensitivity audit of the existing measurements, not a third fitted
oscillator. [Tool](../../../Tools/audit_saw_alias_separation.py) and
[complete results](saw-alias-separation-2026-09-15.json).

## Fixed inputs and methods

The audit retains the exact five 80 ms windows and LP12 hardware-only line masks
from the [asymmetric-kernel experiment](deepsonic-saw-asymmetric-kernels-2026-09-15.md).
Original LP12/LP24 MP3s and performance MIDI are checked against the acquisition
catalog, then freshly decoded. Each LP12 sample hash must match the earlier
experiment. Its W4 coefficients, gain and passage phases are reused unchanged;
all five reconstructed waveform-error measurements must reproduce the baseline.
The later same-note window overlaps the first, and all passages were previously
explored. They are not blind or independent new recordings.

Three methods examine every original eligible line, including weak model lines:

- **Original:** the unchanged harmonic-subtraction/Hann detector.
- **Joint first:** simultaneously fit quadratic complex amplitudes for main
  harmonics below 20 kHz and linear complex amplitudes for both branches
  `|44,100 − h × f0|` between 100 Hz and 20 kHz.
- **Joint first + second:** additionally include both `|88,200 − h × f0|`
  branches as nuisance components. Including these components does not assert
  their presence in the hardware.

Frequencies remain at nominal MIDI tuning throughout. Maximum matrix condition
number is 5.60. Joint measurements report the amplitude at the window center;
the original detector averages within a Hann window. Those quantities can
differ during a moving filter response. Their difference is not a correction
factor or a calibrated uncertainty interval.

## Measured sensitivity

The following errors compare the frozen W4 model with the same LP12 hardware
lines under each method. All values are RMS dB errors, not total sound-quality
scores.

| Passage | Original | Joint first | Joint first + second |
| --- | ---: | ---: | ---: |
| 91 +100 ms, training | 1.467 | 1.494 | 1.447 |
| 91 +160 ms | 1.480 | 1.573 | 1.589 |
| 93 +100 ms | 7.366 | 7.299 | 7.314 |
| 88 +100 ms | 5.601 | 5.450 | 5.488 |
| 86 +100 ms | 1.354 | 1.386 | 1.386 |

Across all frozen lines, the maximum LP12 hardware level change is 0.655 dB
with the first family and 0.520 dB with both families. LP24 changes by at most
0.745 and 0.741 dB respectively. These changes leave the large cross-pitch
failures intact.

The quietest hardware bins have modest residual-based coefficient SNR proxies:
with both families, the note 88 minimum is 9.48 dB and the note 93 minimum is
17.21 dB. This prevents presenting their decimal values as equally precise as
the louder lines. Agreement of estimators does not eliminate shared model error
or authenticate the unknown capture chain.

## Independent synthesis controls

Twenty controls cover two fixed phase patterns, five passages, and presence or
absence of a second-fold stress family. Main-harmonic and first-fold amplitudes
are planted at the measured LP12 joint magnitudes; each second-fold stress tone
is deliberately set to −45 dB/H1. These are known synthetic amplitudes, not
estimates of the hardware's second-fold content. Tones are generated by a direct
additive cosine sum independently of the regression matrix construction.

| Maximum amplitude-recovery error | First family only | Added second-fold stress |
| --- | ---: | ---: |
| Original detector | 0.0067 dB | 0.0117 dB |
| Joint first | <0.000000001 dB | 2.683 dB |
| Joint first + second | <0.000000001 dB | <0.000000001 dB |

The deliberately omitted family can bias the first joint estimator more than
the original Hann detector. A larger regression is therefore not automatically
better. Complete known-family recovery checks matrix indexing and amplitude
extraction, while the omitted-family result supplies a counterexample to an
unqualified joint-estimator accuracy claim. These stationary controls do not
bound every nonstationary waveform, codec, noise or recording-chain effect.

**Decision:** retain the original benchmark detector and the oscillator-model
rejection. Test the synthesis mechanism next; do not compensate the disputed
lines by altering measurement results or globally boosting aliases.

## Reproduce

Use a new output directory:

```sh
OPENBLAS_NUM_THREADS=1 python3 Tools/audit_saw_alias_separation.py \
  --sources build-fidelity/deepsonic \
  --output build-fidelity/high-note-shape/alias-separation-replay
```

The retained run is `alias-separation-v2`. It replaces the pilot control's
matrix-based synthesis with independent additive tones and adds a frozen W4
waveform-reproduction guard. Source, tool, dependency, sample and candidate
baseline identities are included in the JSON. No original audio is committed.
