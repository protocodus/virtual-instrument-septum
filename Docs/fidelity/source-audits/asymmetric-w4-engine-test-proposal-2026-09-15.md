# Asymmetric W4: worthwhile family, but compose it with the actual engine first

**A bounded actual-engine improvement test is justified without first solving every alias notch or identifying Roland's architecture. The saved source-only W4 coefficients are not yet a defensible oscillator-stage transplant.** The minimum prerequisite is a production baseline on the same high-note windows, followed by one W4 correction learned through the frozen current signal path. This is a proposal only: no new fit, render or production edit was performed.

## Why the earlier evidence supports a test, but not the advertised gain

The [asymmetric W4 study](deepsonic-saw-asymmetric-kernels-2026-09-15.md) reduces training waveform residual power from6.2831% to.0397%, with substantial improvements on other pitches. Its alias error is1.47 dB RMS on the training note and1.35 dB on note86; contrary note93/88 notch errors of about17/14 dB remain. Those misses should be retained as regressions/limitations, not used to prohibit any partial improvement experiment.

However, the6.2831% row is **an oscillator-only polyBLEP fit**, not Septum's output. The fitted W4 gain0.290376 and correction coefficients are in recorded-output units; the objective also fits phase/DC and can absorb instrument filtering or capture response. Dividing the coefficients by that gain removes a scalar, not those responses. Adding them ahead of Septum's existing filters can count coloration twice. The earlier [signed FIR](high-note-saw-fir-2026-09-15.md) is likewise an observation-path nuisance model; none of its learned taps belongs in the candidate oscillator.

The actual [dry production replay](dry-envelope-engine-2026-09-15.md) already has post-training spectral distances .28616/.29660 and isolated H2–H8 ratio errors1.002/1.152 dB (LP12/LP24, that audit's common pool). These are different measurements and cannot be compared numerically with6.2831%. Its [phase self-control](dry-phase-sensitivity-2026-09-15.md) produces .203–.250 legacy spectral distance with unchanged timbre. Therefore no claimed improvement should come from the earlier source-only reference or one aggregate short-window score.

## Proposed single candidate, with no nuisance filter

1. **Baseline receipt first, using existing audio.** Apply the established harmonic/alias measurements to the current full dry-engine outputs on the same five high-note windows. Retain actual production output stages and the existing fixed physical timing. This establishes the baseline error that a new source would need to improve; do not refit hardware or search another family.
2. **Freeze one source-stage family:** degree3, C1, half-sample-knot asymmetric W4. Replace only the classic Saw wrap correction, before oscillator mixing. Keep the ramp at unit amplitude; declare analytic zero-mean normalization so an observation-window DC fit does not become oscillator DC before drive. W8 and the previous FIR grid are outside this experiment. Stored W4 coefficients may seed the calculation, but are not the final candidate.
3. **Train through the exact current engine.** Use only the already examined LP12 Q0 note91,80 ms centered at MIDI18.75 s +100 ms. Propagate the source basis through the frozen current low-frequency shelf, moving voice filter, bypassed-drive oversampling path, AMP, master and AnalogOutput. A forward calculation avoids unstable inversion at weak notches. No fitted downstream FIR, filter/ADSR change, EQ, return change or capture filter is allowed. The unresolved capture may still be absorbed in the empirical source correction; retain that attribution limit.
4. **Fix gain and timing separately.** Preserve the dry recipe and its note36 calibration. Use the frozen physical lag−1406 samples, candidate[t+lag], including the existing93-sample renderer delay exactly once. Allow only one training-window nuisance phase/DC while estimating the correction. Do not promote that phase or DC to engine defaults or event timing: full benchmark renders retain the same canonical phase policy as production. A planted known-source control with another phase must verify that the fitting convention transfers the source shape correctly.
5. **Freeze the resulting one coefficient vector before comparisons.** This is a fresh W4 *family* fit conditional on the current engine, not a confirmation of the previous fitted coefficients or a recovered SH-201 mechanism. If the exact downstream operator is not linear under the dry control, or the source-basis fit is numerically unstable, stop and report that prerequisite failure; do not silently replace it with a nuisance FIR or larger search.

The correction must preserve canonical oscillator clocks, pitch and fractional wrap reporting. Keep the existing `corrected=false` hard-sync-reset behavior, and leave Square, Pulse, Triangle, SuperSaw and Feedback oscillator code unchanged. W4 means four samples at44.1 kHz on each side of a wrap. A complete implementation must define the periodic sum when supports overlap at very high pitch, rather than extrapolate the previous nearest-wrap proof beyond its25.06-sample shortest tested period. No extra transport latency is needed for a phase-domain correction; verify it. This first benchmark is explicitly44.1 kHz.

## Numerical integration gates

- Compile baseline and candidate from one frozen source snapshot. Baseline dry WAVs must reproduce LP12 `e960507e6c9404554980eceae90d51e1253347d22fbe7e661f48730dce7484da` and LP24 `dd505cd6a020417a5b86c52083a8dd6091b3f18edbad7c28a0de431df2356a33` before scoring.
- The W4 basis containing ordinary polyBLEP must reproduce the actual engine's Saw control; verify before/after-wrap signs, phase advance-before-output convention, continuity at support endpoints, periodic overlap and analytic DC normalization.
- Verify forward-basis composition against an independently rendered known source through the same complete downstream path. Check full rank/conditioning, state limiting, output clipping and arithmetic linearity rather than assuming Q0 is linear. Preserve voice/effect history and original MIDI ordering.
- Pin original MP3/MIDI, recipe, source, coefficient, renderer and PCM hashes; require finite outputs, unchanged event counts, ended voices and unchanged latency. These are engineering controls, not perceptual-equivalence tolerances.

## Frozen full-engine comparisons

Use the same original124-note performance and existing dry recipe: OSC1 Saw only, Q0, cutoff47, key follow74, depth80, decay53, zero sustain and no drive/effects/LFO depths. No new raw patch fit. Render both LP12 and LP24; LP24 is a useful cross-slope check although already inspected during research.

- Note36 at1.5–1.9375057 s remains calibration only. Primary comparisons share the current baseline's scalar gain; additionally retain each candidate's one note36 gain as sensitivity. No per-note gain, phase or timing fit in benchmark audio.
- Keep the existing before-training, post-training, isolated-note and chord supports, but **remove the entire note91 interval18.75–19.25 s from primary coefficient-validation aggregates**. No STFT frame may span an exclusion. Recompute baseline on identical coverage. The old later note91 window overlaps the fitted window by20 ms and remains a diagnostic only.
- Report512/1024/2048/8192-sample STFT separately,10/50 ms RMS, independent H1/amplitude and H2–H16 ratios, and the frozen hardware-qualified alias lines. Retain quiet-line uncertainty and all candidate validity failures; do not improve an average by dropping newly failed candidate windows. Do not subtract a phase “floor.”
- Keep all five old high-note waveform/alias windows as explicitly exploratory context. The remaining original sequence provides coefficient-validation across register, envelopes and chords, not blind validation of the entire development process. Exact notch reproduction is not required to report a useful improvement, but an audible/new spectral regression must remain visible.

Use all ten unchanged named official preset reconstructions as a second full-engine check. Active classic Saw occurs in **Air Lead1, Brassy Ld1, Dist Bs1, So Juno1 and Vangelead**. **Club Bass, Cotton Wool, Moogie1, Pedal Bs1 and Supa Juce1** have no active classic Saw and must remain byte-identical. This split comes from exact stored controls, not candidate errors; SuperSaw is not changed. Preserve shipping filter/envelope/FX settings and the established original source-clock inputs. Freeze the production-only first-quarter lag/gain policy before candidate scoring; share that baseline gain, with candidate-prefix gain only as a labeled sensitivity. Keep all later supports and all regressions.

Return measured tradeoffs and a common-gain synchronized listening comparison. A consistent full-engine improvement can justify a provisional source correction despite imperfect quiet notches; neither the five exploratory windows nor one mean spectral number can establish whole-instrument equivalence. No new architecture, coefficient or shipping choice is selected by this proposal.
